# Salud Mental II · Content Sweep — Skipped Items

Log of additions that were considered during the Alpha15 content-completeness
sweep but deliberately NOT committed. Rationale for each is one line.

Purpose: when Sebas returns with his course notes (`TOC_Apuntes.docx` etc.),
he can scan this list to see what was intentionally left out and decide
whether any items should be added from the course-specific angle.

Format per section:

## `<Section>`
- `<item>` — skipped: `<reason>`

Reasons are drawn from a small vocabulary:
- **borderline basic** — textbook-standard but on the "nice to have" side, not
  universally taught.
- **placement ambiguity** — couldn't decide cleanly whether it belongs in
  `def` / `cli` / `dx` / `tx`.
- **teacher-specific phrasing** — textbook vs likely-course phrasing differ
  enough that adding from textbook would clash with Sebas's notes.
- **already covered elsewhere** — the fact is present in a sibling disease,
  a shared pearl, or a different tab; adding would duplicate.
- **guideline variation** — first-line choice varies by region/year; too
  unsafe to hardcode.
- **dosing detail** — explicit out-of-scope per the task rules.
- **new primitive needed** — would require adding a visual component; task
  rule forbids.
